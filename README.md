# Cacau House — site pronto para GitHub Pages

Este pacote contém o site completo com layouts para computador e celular.

## Publicar sem instalar programas
1. Extraia este ZIP no computador.
2. Entre em https://github.com/ e crie um repositório público chamado `cacau-house` (New repository). Marque a opção para adicionar um README.
3. No repositório, clique em Add file > Upload files.
4. Envie os arquivos EXTRAÍDOS e a pasta assets, preservando as pastas. O index.html deve aparecer na raiz do repositório, ao lado da pasta assets. Não envie apenas o ZIP nem uma pasta externa contendo todo o site. Se necessário, faça mais de um envio para respeitar o limite de arquivos da interface.
5. Clique em Commit changes para salvar.
6. Abra Settings > Pages. Em Source, escolha Deploy from a branch.
7. Em Branch, escolha main e /(root), e clique Save.
8. Aguarde a publicação. O endereço aparecerá em Settings > Pages (Visit site).

O formato do endereço será https://SEU-USUARIO.github.io/cacau-house/ . SEU-USUARIO é apenas um exemplo: substitua pelo seu nome no GitHub.

## Atualizar depois
Edite ou substitua os arquivos no mesmo repositório e salve com Commit changes. O GitHub Pages publicará a atualização automaticamente.

## Conteúdo do pacote
- index.html: página principal
- guia.html: guia da estadia
- como-chegar.html: chegadas e mapa regional
- torus-e-raposa.html: Instituto Torus e comunidade
- contatos.html: guias e compras
- arredores.html: cachoeiras e passeios
- mapa-torus.html: mapa do Instituto Torus
- CSS, JavaScript e pasta assets: aparência, interatividade e imagens

Não é necessário instalar Node, compilar ou usar GitHub Actions. O arquivo .nojekyll é intencional. Mantenha os créditos e licenças das fotografias presentes nas páginas.

Os mapas de orientação são ilustrativos/esquemáticos; combine os acessos e passeios com a equipe local.
